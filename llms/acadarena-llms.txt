# AcadArena

> AcadArena is a Philippine campus gaming and esports company founded in 2019 that builds student
> communities around games across high-school and college campuses in the Philippines and Southeast
> Asia. It runs a student-club accreditation network, a club incubator, an event-sponsorship
> marketplace, an educator practice community, and collegiate competitions.

AcadArena publishes **no public API**. There is no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, Postman collection, MCP server or A2A agent card on any host it operates.
This file is generated by API Evangelist from the public profile at
https://apis.io/provider/acadarena — it is not published by AcadArena.

## What exists

- [Website](https://www.acadarena.com/): Next.js marketing site; programs, campus stats, contact.
- [Buffs](https://www.acadarena.com/buffs): marketplace where student clubs apply for loot and
  sponsorship for a campus event.
- [Privacy Policy](https://www.acadarena.com/privacypolicy)
- [Discord community](https://discord.gg/acadarenagg): the company's student-facing community.
- [GitHub organization](https://github.com/Arclight-Labs): the org whose `.github` profile README
  titles it "AcadArena Technologies Inc" and whose repositories build tooling for the AcadArena
  platform (ROE2 broadcast overlay, League/Wild Rift draft tools, a Prisma-to-Zod generator). Since
  renamed to Arclight-Labs.
- [@acadarena/zod-prisma](https://www.npmjs.com/package/@acadarena/zod-prisma): the only package
  published under the company's npm scope. Build tooling, not an API client. v0.9.0, 2023-04-09.

## What was checked and is absent

- `/.well-known/security.txt`, `/openid-configuration`, `/oauth-authorization-server`,
  `/oauth-protected-resource`, `/api-catalog`, `/ai-plugin.json`, `/agent-card.json`,
  `/agent.json`, `/aauth-resource.json` — 404, unreachable, or an SPA HTML shell on every host
  (acadarena.com, www.acadarena.com, acadarena-website.web.app, roe2.acadarena.com,
  app.acadarena.com, arclight.acadarena.com, the Supabase project host).
- `/openapi.json`, `/swagger.json`, `/api-docs`, `/docs`, `/redoc`, `/graphql` — no spec on any host.
- `api.acadarena.com` — a dangling DNS record: it is a CNAME to
  `acadarena-api-j88i8.ondigitalocean.app`, which does not resolve.
- The website's own backend is a Supabase project (`aatesefpjfdqshisyriz.supabase.co`). It is
  key-gated: anonymous requests to `/rest/v1/`, `/graphql/v1` and `/auth/v1/settings` return
  HTTP 401. API Evangelist does not use credentials, so nothing there was read or recorded.
- `app.acadarena.com` is a Squarespace site behind site-wide password protection (HTTP 401).
